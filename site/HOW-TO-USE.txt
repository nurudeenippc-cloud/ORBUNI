ORBUNI — COMPLETE SITE FOLDER
=============================

This is the whole site, one zip. Unzip it, then drag the folder straight
into Netlify (or into the Netlify "Deploys" drop zone on your existing
site).

WHAT IS IN HERE
  index.html    the site, including this round's home page changes (below)
  photos/       every university, home, careers and housing photo
  video/        the two home-page product-demo clips (housing + programmes)
  _headers, _redirects, manifest.json, robots.txt, sitemap.xml, sw.js
  badge-96.png, icon-192.png, share.png


ONE FILE TO COPY FROM YOUR OWN FOLDER BEFORE YOU DEPLOY
--------------------------------------------------------
     videos/hafsat-aman.mp4      (note: "videos", plural — a different
                                   folder from "video" above)

This is the tester-review video used elsewhere on the site (not part of this
round's work) and isn't in this zip. Copy it from your current live site's
folder into this one, keeping the same "videos/hafsat-aman.mp4" path, before
you deploy. If you forget, nothing breaks visibly — that page already
degrades gracefully when this file is missing.

(The Fenerbahçe University photo folder mentioned in an older version of
this note is no longer needed — that code path was cleaned up this round,
see below.)
